# ToTo Tools — Ferretería Los Hermanos

Página web y tienda virtual para **Ferretería Los Hermanos! (ToTo Tools)** en Santiago de Cuba. Cuenta con una portada tipo landing y un catálogo interactivo con pedidos directos por WhatsApp. Es un sitio estático (GitHub Pages) que no requiere servidores ni bases de datos complejas.

## Dónde está cada cosa

| Qué | Dónde |
|---|---|
| Todo el contenido (textos, productos, precios, horario, contactos, monedas) | `datos/catalogo.json` |
| Fotos de los productos | `img/productos/` |
| Fotos de la portada, logo e imagen para compartir | `img/marca/` |
| Estilos y lógica de la web | `assets/sitio.css`, `assets/sitio.js` |
| Panel de edición | `editar/` |

## Cómo se edita

Puedes gestionar los productos y precios desde la sección de administración (`editar/`), utilizando una llave de acceso de GitHub (token de grano fino con permisos de lectura y escritura). Al pulsar **Publicar**, se actualiza automáticamente el catálogo en la web.
